# BlockHub - Digital Resources

A Roblox-themed website for digital resources. Built with HTML, CSS, and JavaScript.

## Features
- Roblox-inspired blocky design with blue and yellow colors
- Responsive resource grid with hover animations
- Category filtering tabs
- Scroll-in animations for resource cards
- Mobile-friendly layout

## Getting Started

1. Clone the repository
2. Open `index.html` in any browser
3. Or run a local server:

```bash
# Using Python
python -m http.server 8000

# Then visit http://localhost:8000
```

## File Structure
- `index.html` - Main page structure
- `style.css` - All styling and Roblox theme
- `script.js` - Interactive features (tabs, animations)

# Bloxify - Roblox Game Development Guide

## 1. Project Overview

**Bloxify** is an educational website designed to help beginners learn how to develop games on Roblox. It provides guides, information and resources to introduce users to Roblox game development.

Our goal is to make learning game development easier and more accessible, especially for users interested in creating their own Roblox games.

The website was developed using HTML, CSS and JavaScript through Visual Studio Code and hosted locally using Laravel Herd.

## 5. How to Clone and Run the Website Locally

### Requirements

Before running the project, make sure you have installed:

- Git
- Visual Studio Code
- Laravel Herd

### Step 1: Clone the Repository

Open Git Bash or the VS Code terminal and navigate to your Laravel Herd directory.

```bash
cd ~/Herd
```

Clone the repository:

```bash
git clone [https://github.com/erruleilmie/iib-as03]
```

### Step 2: Open the Project

Navigate into the project folder:

```bash
cd Bloxify
```

Open the project in Visual Studio Code:

```bash
code .
```

### Step 3: Run Using Laravel Herd

1. Make sure Laravel Herd is running.
2. Ensure the Bloxify project is inside Herd's monitored directory.
3. Allow Herd to detect the project and provide its local development domain.
4. Open the generated local domain in your web browser.

Bloxify should now be accessible locally.

## 6. Git Workflow and Collaboration

Our team used Git and GitHub to manage the development process and collaborate on the website.

We followed these steps:

1. **Repository Creation:** A GitHub repository was created for the Bloxify project.
2. **Branch Creation:** Each team member created a separate branch to work on assigned tasks.
3. **Making Changes:** Team members edited and improved the website on their respective branches.
4. **Committing Changes:** Changes were committed with meaningful commit messages.
5. **Pushing Changes:** Each member pushed their branch to GitHub.
6. **Pull Requests:** Team members created Pull Requests to propose merging their changes into the main branch.
7. **Code Review:** Changes were reviewed before merging.
8. **Merging:** Approved Pull Requests were merged into the main branch.

This workflow allowed our team to work independently while keeping the main branch organised.

---

## 7. Merge Conflict Resolution

During collaboration, our team encountered a merge conflict when changes from different branches affected the same part of a file.

To resolve the conflict, we:

1. Identified the file containing the merge conflict.
2. Compared the changes made in both branches.
3. Discussed and decided which changes should be kept.
4. Manually edited the affected file to combine the necessary changes.
5. Saved the corrected file and checked that the website still worked properly.
6. Committed the resolved changes and continued with the merging process.

This helped us understand the importance of communication and coordination when working with GitHub collaborators.
